## Default Permission

O que a janela main do Tomatito usa no Android (capabilities/android.json).

#### This default permission set includes the following:

- `allow-permissoes`
- `allow-cores`
- `allow-pedir-notificacoes`
- `allow-abrir-config-avisos`
- `allow-tocar`
- `allow-abrir-url`
- `allow-acao-pendente`
- `allow-para-o-fundo`
